================================================================
PROCESSOR.PY — CSV BULK UPLOAD
================================================================

- Shuffle pins + schedule bersamaan (zip + random.shuffle) sebelum generate CSV
- Title unik per batch (tidak boleh duplikat), max 20 attempt per pin
  fallback: tambah suffix counter
- AI generate via Gemini kalau AI_ENABLED=True
- Fallback: templates.py (pool title/desc per tipe, rotasi by index)
- CSV format: CRLF line endings (lineterminator="\r\n")
- Kolom: Title | Media URL | Pinterest board | Thumbnail | Description |
          Link | Publish date | Keywords
- Publish date: UTC (WIB - 7 jam), buffer 2 jam sebelum publish
- Pinterest tolak: duplikat affiliate link atau duplikat title dalam satu batch
- JANGAN edit CSV di Excel sebelum upload (merusak CRLF)
- Shopee CDN webp URL diterima langsung oleh Pinterest
