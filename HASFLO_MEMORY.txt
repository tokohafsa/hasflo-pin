PIPELINE LENGKAP (Juli 2026)
================================================================

JALUR A — CAROUSEL PIN (via Hermes + Postiz):
  1. Input URL Shopee manual → paste di app.py Step 1
  2. app.py Step 2: Gemini generate judul + deskripsi Pinterest
     (judul: bebas kreatif ikut keyword trending dari seo_keywords.json)
     (deskripsi kalimat 1: judul Shopee VERBATIM, tidak boleh diubah)
     (deskripsi kalimat 2-dst: keyword trending dari seo_keywords.json)
  3. app.py Step 3: pilih model reference (opsional, filter hijab/non-hijab)
  4. app.py Step 4: deskripsi subject (usia, nationality, hijab/non-hijab)
  5. app.py Step 5: pilih layout collage (JSON dari assets/)
  6. app.py Step 6: generate prompt collage (build_prompt_json)
  7. app.py Step 7: upload bahan_prompt/ ke Dropbox
       → outfit images (imageN.jpg) + layout.jpg + prompt.txt
       → folder name: [ratio_prefix][nama_produk]_[tanggal]
         contoh: [2x3]Dress_Wanita_Motif_Bunga_20260725
  8. User: buka Dropbox → upload semua file ke GPT → dapat hasil collage
  9. app.py Step 8: drag hasil GPT → fit ke canvas + dominant color fill
       → upload ready_pin/ ke Dropbox
       → app rename folder parent: [nama] → READY_[nama]
       Struktur ready_pin/:
         slides/slide1.jpg   ← hasil GPT
         image1.jpg          ← outfit ref 1 (fitted ke canvas ratio)
         image2.jpg          ← outfit ref 2 (dst)
         deskripsi.txt       ← Board/Section
                                Judul pin
                                Deskripsi pin
                                Link affiliate Shopee
 10. Hermes: poll Dropbox → post ke Postiz → pindah ke DONE/

JALUR B — SINGLE IMAGE PIN (via CSV bulk upload):
  1-2. Sama seperti Jalur A
  3. processor.py → generate CSV (shuffle, jadwal WIB→UTC, AI title/desc)
  4. Upload CSV ke Pinterest bulk upload tool

SEO KEYWORDS SYSTEM
================================================================

FILE       : seo_keywords.json (root project)
FORMAT     : JSON dengan struktur title + description per tipe produk
UPDATE     : Otomatis tiap Senin 09:00 WIB oleh Hermes skill
SOURCE     : Google Trends (pytrends, geo=ID) + Pinterest Trends
ANALISA    : Gemini API
PUSH       : Hermes git push ke GitHub → Streamlit Cloud auto-redeploy

STRUKTUR JSON:
{
  "updated_at": "YYYY-MM-DD",
  "week": N,
  "source": ["google_trends", "pinterest_trends"],
  "keywords": {
    "dress": {
      "title": [...],        ← untuk generate judul Pinterest
      "description": [...]   ← untuk kalimat 2-dst deskripsi
    },
    "blouse":   { "title": [...], "description": [...] },
    "tunik":    { "title": [...], "description": [...] },
    "outer":    { "title": [...], "description": [...] },
    "setelan":  { "title": [...], "description": [...] },
    "unknown":  { "title": [...], "description": [...] }
  }
}

FALLBACK: kalau JSON gagal dibaca → pakai SEO_KEYWORDS_DEFAULT
          hardcoded di title_desc_generator.py (app tidak crash)

REFACTOR YANG DIPERLUKAN:
  - title_desc_generator.py : hapus SEO_KEYWORDS dict hardcoded
                               load dari seo_keywords.json
  - app.py                  : hapus SEO_KEYWORDS dict hardcoded
                               import dari title_desc_generator
