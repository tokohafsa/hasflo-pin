HERMES POSTIZ STARTUP FLOW
================================================================

Script START (PowerShell → Task Scheduler):
  1. wsl -d Ubuntu start
  2. docker compose up -d (di /opt/postiz)
  3. Health check loop: ping localhost:5000/health setiap 5 detik
  4. Kalau Postiz ready → Hermes trigger hasflo_post_pin
  5. Post pin ke-1, jeda 5 menit, post pin ke-2

Script STOP (PowerShell → Task Scheduler):
  1. docker compose down (di /opt/postiz)
  2. wsl --shutdown

Health check (lebih reliable dari sleep tetap):
  until curl -s http://localhost:5000/health | grep -q "ok"; do
    sleep 5
  done
